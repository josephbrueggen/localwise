# Localwise

Hyper-local, easy-to-read insights for Main Street small businesses. Localwise is an early product, built in public, one piece at a time.

## 👉 [View the live design showroom](https://localwise-showroom.pages.dev)

**[localwise-showroom.pages.dev](https://localwise-showroom.pages.dev)** is the interactive showroom of the components that make up the Localwise website: the header and footer, logo, the rotating headline word, the sample report card, the hero map illustration, the waitlist form in each of its states, and the design tokens (colors, type and spacing).

**Live site:** [localwise-79q.pages.dev](https://localwise-79q.pages.dev)

## What's in this repo

- The website: a landing page and a privacy and contact page, built with Next.js and hosted on Cloudflare Pages.
- The Storybook showroom (`stories/`), which is published to the link above.
- The design tokens (`design-tokens.css`) shared by the site and the showroom.

Sign-ups and other private parts of the product live in separate, private services. No keys, passwords or customer information are kept in this repository.
